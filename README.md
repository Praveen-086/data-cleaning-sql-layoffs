# Data Cleaning with SQL — Layoffs Dataset

## 📌 Project Overview

This project focuses on cleaning and preparing a layoffs dataset for further analysis using MySQL.

The project was completed as part of **Alex The Analyst's 2026 Data Analyst Bootcamp** and helped me practice practical SQL data-cleaning techniques.

## 🛠️ Tools Used

- MySQL
- MySQL Workbench

## 🧹 Data Cleaning Process

The following steps were performed:

1. Removed duplicate records
2. Standardized company names and categorical values
3. Cleaned country values
4. Converted date values into the proper DATE format
5. Handled NULL and blank values
6. Populated missing industry values where possible
7. Removed records with insufficient layoff information
8. Removed unnecessary columns
